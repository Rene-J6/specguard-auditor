# SpecGuard - AI Coding Instructions

## Project Overview

SpecGuard is a local-first AI platform that audits Software Requirements Specification (SRS) documents.

Target users are software companies and development teams who want to evaluate their SRS before system development.

Current scope:
- English documents
- PDF and image input
- Local deployment only
- Human-in-the-loop validation

---

## Core Objective

The system should:

1. Extract text from uploaded documents.
2. Detect software requirement statements.
3. Retrieve the most relevant standards from the knowledge base.
4. Analyse requirement quality.
5. Explain compliance issues.
6. Suggest improved requirement rewrites.
7. Allow expert review.
8. Collect validated data for future manual fine-tuning.

## Knowledge Base

Current standards include:

- ISO/IEC/IEEE 29148
- ISO/IEC 25010
- ISO 9001
- Industry4WRD
- MyDIGITAL

All standards are stored inside ChromaDB.

Never replace local retrieval with online APIs.

---

## Fine-tuning Workflow

Initial training uses synthetic data generated by Gemini.

Training schema:

- bad_requirement
- document_reference
- analysis
- suggested_rewrite

After deployment:

Expert-approved results should be converted into the SAME schema.

Training is always started manually.

Never trigger automatic fine-tuning.

The system only prepares new training data.
